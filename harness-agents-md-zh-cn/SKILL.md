# 驾驭 AGENTS.md

仅在用户明确提出上述指令编辑请求时使用本 Skill。普通 Git、发布、实现和编码
工作不在范围内。

## 选择基准

1. 查找当前生效的全局指令源。Codex 中应解析当前 Codex home，并依次使用首个
   非空的 `AGENTS.override.md` 或 `AGENTS.md`。其他宿主使用其文档规定的全局
   指令源，不要猜测。
2. 全局指令存在时，将其作为精确基准。除非用户要求修改，否则保留其语言、
   术语、阈值和意图。不要混入内置 fallback。
3. 确认全局指令缺失时，使用 `assets/AGENTS.example.md` 作为工程 fallback
   并继续。说明使用了 fallback。无法访问不等于确认缺失。
4. 读取目标文件及适用的项目指令。仅针对项目的请求可以继承全局规则，但不
   授权修改全局文件。

## 做最小且有用的修改

- 只修改用户要求的指令范围。
- 新增规则只能来自用户要求、所选基准或已验证的仓库事实。
- 不要编造通用工作流、发布清单、进度追踪、Schedule 或宿主专用机制。
- 保留兼容的原文，合并重复规则；没有合理改动时应直接说明。
- 检查最终 diff，并报告所选基准、修改范围和已执行的验证。
